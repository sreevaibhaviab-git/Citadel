CITADEL // LIVE TRAFFIC + EVENT RESPONSE BOARD

LIVE TRAFFIC
- TomTom flow speed/free-flow/confidence is sampled around the Bengaluru demo district.
- Every simulated road segment binds to its nearest live flow sample.
- Civilian vehicle agents change speed per road using the live speed/free-flow ratio.
- Adaptive traffic signal green time is calculated from congestion on roads adjacent to each signal.
- Roads remain visible when the Traffic layer is enabled and are colour-coded:
  GREEN free, AMBER moderate, ORANGE heavy, RED gridlock/closed.
- Click a road to inspect current speed, free-flow speed, congestion, capacity,
  TomTom confidence, and CITADEL modelled vehicles on that segment.

IMPORTANT DATA PROVENANCE
TomTom Traffic Flow does not provide CITADEL with an exact literal car count for
these segments. Vehicle count is therefore labelled MODELLED. Live speed and
free-flow speed are kept separate and labelled TOMTOM LIVE.

EVENT RESPONSE BOARD
- Collision/fire/random road events automatically open LIVE OPS once.
- Major disasters expose the same response network inside the Scenario Console.
- Board shows counts and nearest mapped names for hospitals, fire stations,
  police stations and safe/assembly locations from OpenStreetMap Overpass.
- It also shows EMS/fire/police response batch estimates, clearance ETA,
  stabilization ETA and alternate routes.
- Road alternatives are generated by CITADEL's Dijkstra graph with the affected
  segment banned, and display corridor sequence, distance, ETA and extra delay.

LIVE / SIMULATION SWITCH
LIVE FUSION: Open-Meteo + TomTom + OSM influence the model.
SCENARIO LAB: live influence pauses and weather/traffic/disasters are manual.
