  git push

What this patch adds:
- Bengaluru location/road/POI search using Nominatim.
- Hover any CITADEL or live TomTom road for a floating glass road card.
- Card shows speed, free flow, congestion, estimated/modelled cars, and nearby hospitals/police/fire within 5 km.
- Emergency vehicles use TomTom traffic-aware routing in LIVE mode and follow returned real road geometry.
- If routing is unavailable, the existing CITADEL Dijkstra route remains the fallback.
